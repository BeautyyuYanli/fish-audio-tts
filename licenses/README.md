# License maintenance

The project's original code is Apache-2.0; [LICENSE](../LICENSE) and [NOTICE](../NOTICE) are distributed with every APK. Upstream components keep their own licenses. Fish Audio model weights, account credentials and user voice recordings are not included.

`catalog.json` is the reviewed input for Android runtime coordinates, native project owners and upstream notice sources. Files in `upstream/` are verbatim upstream texts or source data, fetched with their tools rather than hand-edited. Their URLs, pinned versions and SHA-256 hashes are recorded in the catalog. AndroidX's text comes directly from the published core 1.17.0 AAR. Use `python3 tools/fetch-license-sources.py` from the repository root to restore the reviewed files; a changed upstream response fails its checksum check. Python is needed only for this maintenance command.

`npm run licenses` reads every installed production npm package selected by `package-lock.json`, preserving its full LICENSE/COPYING, NOTICE and copyright files. This conservatively includes production package transitive dependencies even when Vite removes their code. The explicit `npmRuntimeHelpers` list additionally preserves notices from Vite, the Vue plugin and Rolldown for generated runtime helpers such as the module-preload polyfill; the tools themselves are not shipped. Native test dependencies are not included. Missing license texts, mismatched npm versions or altered reviewed upstream sources fail generation.

The generator writes `public/licenses/notices.json`, a readable `THIRD_PARTY_NOTICES.txt` and `public_suffix_list.dat`. Vite and Capacitor copy these generated assets into `assets/public/licenses/` in the APK. Do not edit `public/licenses/`, `dist/` or Capacitor's copied web assets. The panel reads only the local JSON, renders text with Vue escaping and preserves open forms. All license checks happen during the build; the installed app only displays bundled text when requested. License viewing requires no network connection.

Each debug/release Gradle assets merge checks the actual resolved runtime artifacts, versions, native projects and bundled native notice texts. To update an Android dependency, inspect `./gradlew :app:dependencies --configuration releaseRuntimeClasspath` from `android/`, review its source licenses/NOTICE files, update the catalog and upstream files, then run `npm run android:debug`. Unexpected modules, versions or native projects fail the build. Check both variants when their dependencies differ. Adding a new npm dependency also requires reviewing whether its license imposes distribution obligations beyond including its text.

OkHttp 4.12.0 includes an unmodified Public Suffix List under MPL-2.0. Its complete license, original notice and corresponding source data are distributed together. The vendored `.dat` comes from OkHttp's exact release tag; its 9,499 rules and 8 exceptions match the rules in the library's compressed resource. Preserve this source association when upgrading OkHttp. The binary resource is unchanged; no MPL-covered library code was modified.

To inspect an APK, list `assets/public/licenses/` with `unzip -l`, then read `THIRD_PARTY_NOTICES.txt` or extract the JSON and data file. Check Vue and Capacitor MIT copyright/permission text, Apache Cordova/Kotlin/coroutines notices, AndroidX/OkHttp/Okio and the MPL license/source. Rebuild using the documented commands after dependency changes; do not replace a license text with its name or a web link alone.
